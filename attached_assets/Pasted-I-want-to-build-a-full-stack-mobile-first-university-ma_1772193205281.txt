I want to build a full-stack mobile-first university management application. The app should solve sessional management problems in my university (Mehran University).

Project Name: UniTrack – University Sessional Management App

Problem Statement

In my university, sessional marks are assigned based on:

Assignments

Sessional Tests

Presentations

Currently:

Assignments are submitted sometimes on MS Teams and sometimes on Google Classroom.

Tests are conducted on different platforms without consistency.

Teachers communicate presentation/test updates through CR (Class Representative).

Many students are unaware of course outlines.

There is no centralized platform for sessional management.

This app should centralize everything into ONE platform.

🎯 App Goals

Build a mobile-first web app (PWA style) that includes:

Student Panel

Teacher Panel

CR Panel

Admin Panel

Use modern stack:

Frontend: React (mobile responsive UI)

Backend: Node.js + Express

Database: MongoDB

Authentication: JWT

File Upload: Cloudinary or local storage

Deployment-ready structure
